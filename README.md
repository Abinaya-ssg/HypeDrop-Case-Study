
# 👟 HypeDrop

## Overview

HypeDrop is a Gen Z-focused sneaker, Accessories and streetwear shopping app designed in Figma.

The goal of the project was to create a modern shopping experience that feels visually engaging, fast, and personalized for young fashion enthusiasts.



## Target Audience

- Gen Z Users
- Sneaker Enthusiasts
- Streetwear Shoppers
- Fashion-conscious Consumers



## Tools Used

- Figma



## Key Features

- Modern UI Design
- Personalized Shopping Experience
- Product Discovery
- Wishlist Functionality
- Smooth User Flow
